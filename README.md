# Реализация программы

Программа вычисляет значение функции \(F\) для двух пар значений x и y, а затем выводит результаты на экран.
В начале программы объявляются три переменные типа double: x и y — аргументы функции, а F — переменная для хранения результата. Затем переменным присваиваются значения x = 1.9 и y = -1.0.
После этого вычисляется значение функции по формуле: 2,33 умножить на натуральный логарифм квадратного корня из \(1 + \cos^2(x)\), затем разделить на сумму \(e^y\) и \(\sin^2(x)\). Результат сохраняется в переменной F. Функции cos, sin, sqrt, log и exp выполняют вычисления косинуса, синуса, квадратного корня, натурального логарифма и экспоненты соответственно.
Первая команда printf выводит значения x, y и F. Формат %.2f показывает число с двумя знаками после запятой, а %.6f — с шестью.
Затем программа задаёт новые значения: x = 1.6 и y = -2.3e-6, где e-6 означает умножение на \(10^{-6}\). Функция вычисляется повторно, и результат выводится второй командой printf. Формат %.1e выводит y в научной записи с одним знаком после запятой, а %.6e выводит F в научной записи с шестью знаками после запятой.
Чтобы программа компилировалась, в начале файла обычно подключают заголовки <stdio.h>, <math.h> и <locale.h>.

# Директивы препроцессора

define _USE_MATH_DEFINES

include <stdio.h>

include <locale.h>

include <math.h>

# Код

int main(void)
{
    setlocale(LC_ALL, "RUS");

    double x, y, F;

   
    x = 1.9;
    y = -1.0;
    F = 2.33 * log(sqrt(1.0 + cos(x) * cos(x)))
        / (exp(y) + sin(x) * sin(x));
    printf("F(%.2f, %.2f) = %.6f\n", x, y, F);

   
    x = 1.6;
    y = -2.3e-6;
    F = 2.33 * log(sqrt(1.0 + cos(x) * cos(x)))
        / (exp(y) + sin(x) * sin(x));
    printf("F(%.2f, %.1e) = %.6e\n", x, y, F);

    return 0;
}
